# AI Laboratory Programs

A self-contained set of Python implementations for the nine experiments in the supplied AI laboratory list. Each experiment is in its own folder and runs using only the Python standard library (Python 3.10+).

## Open and run in VS Code

1. Open this folder in VS Code.
2. Select a Python 3.10+ interpreter.
3. Open the terminal and run an experiment, for example:

   ```bash
   python experiment_01_agents/main.py
   ```

Or run the interactive launcher:

```bash
python main.py
```

## Experiment map

| Folder | Topics |
|---|---|
| `experiment_01_agents` | Simple reflex, model-based, goal-based, utility-based agents |
| `experiment_02_environments` | Environment property demonstrations |
| `experiment_03_local_search` | Hill climbing, simulated annealing, local beam search |
| `experiment_04_uninformed_search` | BFS, DFS, depth-limited search, bidirectional search |
| `experiment_05_heuristic_search` | Greedy best-first, A*, AO*, memory-bounded search |
| `experiment_06_adversarial_search` | Minimax, alpha-beta pruning, tic-tac-toe |
| `experiment_07_csp` | Map colouring, cryptarithmetic, local search for CSP |
| `experiment_08_knowledge_base` | Forward and backward chaining examples |
| `experiment_09_uncertainty` | Bayesian reasoning and a fuzzy inference system |

Every program contains fixed sample data plus comments explaining where to change it for another use case.
